How It Works
  • Queries the free nationalize.io REST API in real-time — no API key required.
  • Flags are served from flagcdn.com using ISO 3166-1 alpha-2 country codes.
  • Probabilities are sorted from highest to lowest. The top result is the most likely nationality.
  • Bulk mode sends one API request per name. Rate-limit: ~1 000 names / day on the free tier.
